# Ecommerce-Sales-Dashboard
# 🛒 E-Commerce Sales Analytics Dashboard

## 1. Project Title / Headline

**📊 E-Commerce Sales Analytics Dashboard**

An interactive Power BI dashboard designed to analyze e-commerce sales performance, profitability, customer behavior, product categories, payment methods, and regional sales trends.

---

## 2. Short Description / Purpose

The **E-Commerce Sales Analytics Dashboard** is an interactive Power BI report developed to provide a comprehensive view of e-commerce business performance. The dashboard enables users to analyze key business metrics such as **sales amount, quantity sold, profit, and average order value (AOV)** while exploring trends across states, product categories, sub-categories, customers, payment modes, and months.

The dashboard is designed to help users identify **top-performing products and customers, profitable sub-categories, regional sales patterns, preferred payment methods, and monthly profit trends** for better data-driven decision-making.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Main data visualization and dashboard development platform.
* 🧹 **Power Query** – Used for data cleaning, transformation, and preparation.
* 🧮 **DAX (Data Analysis Expressions)** – Used to create calculated measures and business metrics.
* 🗂️ **Data Modeling** – Used to organize and establish relationships between the available data tables.
* 📈 **Power BI Visualizations** – Used to create interactive charts, KPI cards, slicers, and analytical views.

---

## 4. Key Performance Indicators (KPIs)

The dashboard provides an overview of the business through the following KPIs:

* 💰 **Total Amount / Sales** – Overall sales generated.
* 📦 **Total Quantity** – Total number of products sold.
* 📈 **Total Profit** – Overall profit generated from sales.
* 🧾 **Average Order Value (AOV)** – Average value generated per order.

These KPIs provide a quick snapshot of overall e-commerce performance.

---

## 5. Dashboard Features & Analysis

### 🌎 Sales by State

Analyzes sales performance across different states to identify regions contributing significantly to overall revenue.

### 📦 Category-wise Quantity

Shows the quantity of products sold across different product categories, helping identify categories with higher sales volume.

### 📊 Profit by Sub-Category

Analyzes profit generated by individual sub-categories to identify the most and least profitable product segments.

### 💳 Payment Mode Analysis

Provides insights into customer payment preferences by comparing different payment methods used for purchases.

### 👥 Top Customers

Highlights customers contributing significantly to the overall sales, helping identify high-value customers.

### 📅 Monthly Profit Analysis

Displays profit trends across different months, making it easier to identify profitable and less profitable periods.

---

## 6. Interactive Filters

The dashboard includes interactive filters that allow users to explore the data dynamically:

* 📍 **State**
* 📅 **Quarter**

These filters allow users to drill down into specific geographical regions and time periods.

---

## 7. Key Insights

The dashboard can be used to identify important business insights such as:

* Which states generate the highest sales?
* Which product categories have the highest sales volume?
* Which sub-categories generate the most profit?
* Which payment methods are most commonly used?
* Who are the top customers by sales?
* How does profit change from month to month?
* Which regions, products, and customer segments require further attention?
